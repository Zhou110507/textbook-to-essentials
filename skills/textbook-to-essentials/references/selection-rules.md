# 学科适配与删减判据

## “最小充分”按能力验收

一条内容至少贡献以下一项：界定概念、识别适用条件、连接先修与结论、选择模型、完成关键推导、解决独立题型、检查结果。若只有换说法、换数字、装饰或重复提醒，删除或合并。

不可用字数或公式数量代替信息质量。以下删减通常会破坏精度：

- 把充分条件写成充要条件；把某模型的性质写成普遍结论。
- 删掉比较结论的相同条件，例如固定最高温度与固定输入能量。
- 把导数的固定量、坐标／参考方向、单位质量基准或标准态视为可省略的符号。
- 把近似等号写成等号；从计算中删除改变了模型的假设。
- 把“能量守恒”与“过程可实现”、“存在解”与“唯一解”、“收敛”与“稳定”等不同判断合并。
- 为了简介而删除题意中决定模型的装置连接、约束、边界或数据出处。

## 按课程的核心活动调整

| 课程内容 | 必须保住 | 最适合压缩的内容 |
|---|---|---|
| 物理／工程建模 | 对象、假设、守恒律、闭合关系、约束、符号、量纲、极限与失效边界 | 重复代入与不影响模型的装置说明 |
| 数学／理论 | 定义中的量词、定理前提、结论范围、证明关键构造、反例、条件之间的关系 | 常规运算；不可省略本身作为目标的证明 |
| 电路／控制 | 拓扑、参考方向、初值、激励、连续性／开关条件、传递关系及适用域 | 同一模型下只换数值的例子 |
| 算法／计算方法 | 输入输出、前提、不变量、正确性、收敛条件、误差、时间与空间复杂度 | 重复轨迹；不能只给最终伪代码 |
| 化学／材料 | 组成与计量基准、相态、标准／参考态、反应方向、守恒、近似与实验条件 | 重复物性说明；不可删除影响比较的参考基准 |
| 实验／测量 | 测量模型、仪器量程与分辨率、校准、操作影响、误差传播、数据处理及有效数字 | 与操作和误差无关的仪器历史背景 |

这些是检查维度，不是向教材添加新章节的许可。教材没讲的高级理论不要为“通用性”塞进正文。

## 题型选择

按“决策路径”去重：模型相同、方程相同且只换数据的题合并；模型识别、约束、未知量闭合或检验方式改变的题应单列。概念题按错误推理去重，优先揭示不成立的逆命题、缺少的条件和边界情形。

一张方法卡用完整短段或紧凑列表即可，不必给每题五个醒目标题。含参数或数值的例题需计算，推导题需逻辑闭合，不能用“代入可得”掩盖核心步骤。

## 去拖沓的最后一遍

1. 一概念一处定义，后文用交叉引用；分清首次解释与必要局部条件。
2. 同源公式放一起，通用式与特例用条件连接；复杂大表宁拆不缩字。
3. 引言、学习建议、总结不重复已经明确的知识；不默认添加励志语、自测清单和长篇学习计划。
4. 概要的篇幅服从核心知识密度；题解的篇幅服从方法差异，二者不设统一比例。
5. 讲义中保留学生实际需要的来源定位；逐页审计和编辑讨论放入独立账本。
