# 成对材料分析：学习编辑决策

首次使用配套精要作范本时读本文件。以下方法抽象自《工程热力学》第 2 版与《工程热力学精要与题解》的对照，不把热力学概念或其章节布局强加给其他课程。具体校准证据见仓库 `research/pair-study.md`（安装后的 skill 不依赖该研究报告）。

## 对齐单位

按“知识与方法”对齐，不按页数或标题逐字匹配。将教材中的一个定义、一组总方程及特例、一个证明目标或一种题型作为单元。先核对版本和符号；记录 PDF 页序与印刷页码，目录只用于定位。

全书先建立章级映射，再逐章阅读教材的正文、例题、思考题、习题和对应精要。每页记录已读、需回看公式／图、无法识别或非内容页；只有完成原图复核才能清除待核项。不要为了追求覆盖数字将 OCR 完成标成内容理解完成。

相同题号仍须核对题干、边界、物量基准与数据；不得混用一版题干与另一版答案。

工作笔记可以很详细，学生讲义应精练。书中前言的“适合考试”“教学要求”只能作为该书编者的定位；用户课程的考试范围需要独立证据。

## 对每种编辑决策追问

| 决策 | 应留下的证据 | 可迁移规则 |
|---|---|---|
| 保留 | 对概念判断、模型选择或解题不可缺 | 核心性由功能决定，不由原文篇幅决定 |
| 合并 | 多小节归于同一支配关系，条件差异仍可见 | 总式＋条件分支比重复抄写更紧凑 |
| 改写 | 从叙事、推导或操作过程变成可用结论 | 保住推理转折点，删掉机械展开 |
| 迁移 | 知识被移到问答、题解、附录或后续章节 | 全文检查承接位置，不能误判为删去；账本使用 defer 并写明位置 |
| 省略 | 在目标范围内没有新增能力，或由前置课程承担 | 列出理由；目标改变后重新判断 |

特别检查“正文未讲、题解却反复用”的方法。精要的知识不只在概要中，也藏在辨析、比较表、解题提示和题目条件中。

从各章归纳共同规则，同时记录例外。某章没有内容概要可能是配套材料的编排选择，不是该章知识不重要。样本精要第11章直接采用问答与题解组织整章，可借鉴问题驱动的组织方式，不能硬补四个栏目。某节省略也不能推断它在其他学校不考。

## 从样本迁移

下列结构经常有价值，但都须由本学科内容决定：

- “本章要求”形成内容边界；“概要”提供可直接应用的关系；“辨析”堵住错误的逻辑跳跃；“题型”训练模型选择。
- 总方程与特例同时出现：特例必须带被忽略项及条件；不要用一张设备公式表遮掉推导关系。
- 同一问题用不同系统、坐标、证明策略或算法求解：提炼方法选择理由和结果一致性，不重复所有算术。
- 比较结论与比较基准绑定；例如相同输入、相同约束、相同成本下的优劣可能不同。
- 表图用于状态判别或查值时，提炼查用路线与插值方法，并保留外部数据依赖；不得用似是而非的公式取代。

## 完成校准后

写成少量可执行的规则，每条至少有跨章节支持或明确标为局部例外。输出新的精要时独立表述、另选有必要的少量算例；不要把原书题解量当作默认精要长度，更不要预设全书压缩为某个百分比。
